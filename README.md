# Discord-Bot-Learning

Repo made to learn how to make basic Discord bot in Rust using Serenity crate.

## Goals
- Basic Ping-Pong
- React to specific lines 
- "/" commands
- Make it possible to add more "reaction" commands

More ideas may be added later

## Extra Goals not related directly to bot 
- Not using AI to generate code (but its okay as explenation for concepts)
- learnig how to work with JSON format in Rust
